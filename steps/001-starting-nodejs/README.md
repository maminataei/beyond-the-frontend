# 001 — Starting Node.js

This was the first step in my journey beyond frontend engineering.

After spending most of my career working with JavaScript and TypeScript on the frontend, I decided to start learning the backend side of the JavaScript ecosystem with Node.js.

## Starting Point

To build a structured foundation, I completed the Udemy course:

**[Node.js, Express, MongoDB & More: The Complete Bootcamp](https://www.udemy.com/course/nodejs-express-mongodb-bootcamp/)**

I went through the full course while coding along with the instructor and implementing the projects and exercises introduced throughout it.

My goal wasn't only to watch the material. I wanted to work with the concepts directly, write the code myself, run into problems, debug them, and get comfortable working in a backend environment.

The projects from this step are guided implementations based on the course rather than independently designed projects. Their purpose was to help me build an initial hands-on foundation in Node.js and backend development.

## Why Node.js?

JavaScript and TypeScript have been the main languages I've used throughout my frontend career.

Node.js gave me a familiar language while exposing me to the server side of the systems I've mostly interacted with from the client.

That included areas such as:

- servers
- HTTP
- APIs
- backend architecture
- databases
- authentication and authorization
- application security
- server-side performance
- deployment

Many of these concepts were already familiar to me from the frontend side.

I've consumed APIs, implemented authentication flows, handled application state around server data, worked with caching, error handling, monitoring, and complex client-server workflows.

This course let me work with those ideas from the backend side as well.

## Learning by Building

Throughout the course, I implemented the projects alongside the instructor.

At this stage, the goal was not originality. It was hands-on practice and understanding.

Writing the code myself helped me move from knowing backend concepts mostly as a frontend consumer to actually working with server-side JavaScript, APIs, databases, authentication, middleware, and backend application structure.

## What This Step Represents

This step represents my first structured, hands-on experience with Node.js and backend development.

The course provided the structure, and implementing its projects gave me practical exposure to the concepts instead of only watching them being explained.
