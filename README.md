# Beyond the Frontend

A personal record of my journey from Front-End Engineer to Full-Stack Software Engineer.

I'm a Front-End Engineer with 7+ years of experience working primarily with React, Next.js, TypeScript, and JavaScript.

Over the years, I've worked with APIs, authentication, complex application flows, state management, caching, performance, observability, and frontend architecture.

Now I want to understand the other side of the systems I've been building.

I want to go deeper into Node.js, backend engineering, databases, infrastructure, security, and the architectural decisions behind production applications.

## Why This Repository Exists

This is not a predefined roadmap or a collection of tutorials.

It's a record of my learning process.

I don't want to define the entire journey before I've taken it. Instead, I'll document the path as I go.

Every step represents something I've actually studied, experimented with, built, broken, debugged, or understood better.

The roadmap will emerge from the journey itself.

## How I'm Learning

For each topic, I try to go beyond simply learning how to use an API or library.

I want to understand:

- what problem it solves
- how it works
- why it behaves the way it does
- what happens underneath the abstraction
- common mistakes and edge cases
- how it is used in production systems
- how it connects to concepts I already know from frontend engineering

Each learning step may contain notes, experiments, code examples, questions, mistakes, and conclusions.

## Learning Log

The journey is documented step by step as I learn.

Each step will focus on something I've actually explored, rather than following a fixed public roadmap.

I intentionally don't maintain a complete roadmap here.

The next step will be decided based on what I learn from the current one.

## Current Direction

For now, I'm starting with Node.js and backend fundamentals.

From there, I'll continue exploring whatever concepts are necessary to better understand how complete software systems are designed and built.

## The Goal

The goal isn't simply to add Node.js to my list of technologies.

It's to become an engineer who can reason about and work across the entire application stack.

Frontend is where I started.

This repository documents what comes next.
